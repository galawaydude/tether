# tether

Persistent, re-attachable coding-agent sessions from a browser or phone.

Start a coding agent on a machine you own, close your laptop, and pick the same
session back up from anywhere — with the process and the conversation still alive.

tether is provider-neutral by design. Claude Code, OpenAI Codex, and OpenCode are
all first-class targets, and provider credentials stay on your own machine.

Self-hosted first.

## Status

Early development. Architecture and stack are being defined.
